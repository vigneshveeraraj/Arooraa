# /grow-your-business — photography record

Every photograph used by the Tamil campaign page's website concepts. All are **CC0 1.0** (public domain dedication):
free for commercial use, no attribution required. Attribution is recorded here anyway, as good practice.

**How each licence was checked:** the photo's own StockSnap page was opened in a browser and confirmed to show the
CC0 label and to link to <https://stocksnap.io/license> and <https://creativecommons.org/publicdomain/zero/1.0/>.
Openverse's index (which also lists each as CC0) was used only to find the photos, not as the licence evidence.
Images from sources whose pages could not be checked (rawpixel) were not used.

**Resolution:** these are StockSnap's 960 px web renditions, re-encoded to WebP (native size, never upscaled,
light sharpening). Full-size originals (listed on each source page) can be dropped in at the same paths for
sharper rendering on high-density screens; StockSnap's download button sits behind a bot challenge, so they
have to be downloaded by hand.
